ELECTRONICS RENTAL PLATFORM

Open index.html in a browser.

Features:
- Product search
- Electronics rental booking
- Rental start/return dates
- UPI payment validation (demo)
- Card payment validation (demo)
- Cash on Delivery option
- Total rental amount calculation
- Booking success confirmation
- Automatic window-close attempt after booking

IMPORTANT:
This is a frontend JavaScript demo. Payment validation is local/demo only.
It does NOT process real payments and does not connect to a bank, UPI provider,
or payment gateway. For real payments, connect a backend and a payment gateway
such as Razorpay/Stripe and verify payment on the server.
